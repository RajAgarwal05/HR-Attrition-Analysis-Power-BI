# HR Attrition Analysis – Power BI

This project analyzes employee attrition using the IBM HR Analytics dataset.  
The goal is to identify key factors influencing employee resignation such as department, age, salary, total working years, job role, and gender.

Key Features
- Interactive Power BI Dashboard  
- Custom KPI Cards (Attrition Rate, Average Age, Average Salary, Total Employees)  
- Age-wise Attrition Distribution  
- Job Role-wise Attrition Analysis  
- Gender Distribution (Donut Chart)  
- Attrition by Total Working Years  
- Slicers for Department & Gender  
- Actionable insights for HR decision-making
